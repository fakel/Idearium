# Semilla del curso Idearium

Esta carpeta contiene las 22 notas del curso **Idearium: cómo se construyó**, la documentación teórica que explica el problema, las decisiones y la implementación del proyecto.

- `aprendizaje/idearium/0000 Indice.md` … `0021 Glosario y referencias.md`
- Se copian a `<vault>/Aprendizaje/Idearium/` al arrancar **solo si el vault no contiene ninguna nota Markdown**.
- Si ya hay notas, no se copia ni se sobrescribe nada.
- Para desactivar la copia: `SEED_ON_EMPTY=false`.
- Para usar otra carpeta: `SEED_DIR=...`.

La semilla es parte de Idearium y se distribuye bajo la licencia BSL 1.1 del proyecto (ver `LICENSE`).
